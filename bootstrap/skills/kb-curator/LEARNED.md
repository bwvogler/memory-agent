# What curating this knowledge base has taught us

`kb-curator` ships inside the application image, so its text cannot be changed
from here. This file is where its lessons live instead: preferences scoped to
curation, and corrections a reflection turn drew from real evidence. The skill
reads it when it loads, so an entry here reaches every turn that curates and no
turn that does not — which is the whole reason it is not in `memory/CLAUDE.md`.

Entries win over the general guidance in the skill when the two conflict, and a
later entry wins over an earlier one. Reflection may only append; an ordinary
turn may rewrite this file freely, and there is usually a `consolidate` bead
asking it to.
